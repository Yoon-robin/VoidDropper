# Void Dropper

**Escape from Tarkov 자동 레이드 앱**

Made by **robin** · 디스코드 `@zxc.robin`

---

## 내려받기

[**최신 판 받기**](https://github.com/Yoon-robin/VoidDropper/releases/latest)

압축을 풀고 `VoidDropper.exe` 를 **마우스 오른쪽 → 관리자 권한으로 실행**.
설치 과정은 없습니다.

> **관리자 권한이 꼭 필요합니다.** 게임이 관리자 권한으로 돌기 때문에,
> 일반 권한으로 켜면 클릭이 게임에 들어가지 않습니다.

## 무엇을 하나요

- 레이드를 정해진 횟수(또는 시간)만큼 반복해서 돕니다
- 맵을 여러 개 고르면 한 판씩 번갈아 돕니다
- 헬스장 운동과 지구력 훈련을 대신 눌러 줍니다
- 게임이 꺼지거나 얼어붙으면 알아서 되살립니다
- 텔레그램 봇을 연결하면 폰으로 진행 상황을 받고, 멀리서 멈출 수 있습니다
- 탈출과 사망을 따로 세고, K/D 도 같이 봅니다

## 알아 두면 좋은 것

- 게임 해상도 **1920×1080** 기준입니다
- 설정과 기록은 `%LOCALAPPDATA%\VoidDropper` 에 따로 저장됩니다.
  새 판으로 덮어써도 그대로 남습니다
- 새 판이 나오면 앱이 켜질 때 알려 줍니다

## 새 판으로 바꾸기

1. 앱을 끕니다
2. 새 zip 을 풀어 폴더째 덮어씁니다
3. 다시 관리자 권한으로 실행

## 잘 안 될 때

앱의 **설정 → 진단 자료 모으기** 를 누르면 폴더가 하나 열립니다.
그 폴더를 압축해서 디스코드로 보내 주세요. (텔레그램 토큰 같은 것은 안 들어갑니다)
